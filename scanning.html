🔎 Scanning & Enumeration

Ethical Hacking-এর একটি গুরুত্বপূর্ণ ধাপ। অনুমোদিত সিস্টেম সম্পর্কে নেটওয়ার্ক, পোর্ট ও সার্ভিসের মৌলিক তথ্য বোঝার জন্য এই ধারণাগুলো শেখা হয়।

📚 Scanning কী?

Scanning হলো কোনো অনুমোদিত সিস্টেম বা ল্যাব সম্পর্কে নির্দিষ্ট প্রযুক্তিগত তথ্য বোঝার একটি পদ্ধতি। নিরাপত্তা পরীক্ষায় এটি সম্ভাব্য ঝুঁকি চিহ্নিত করতে সাহায্য করে।

🎯 কী জানা যেতে পারে?

  • কোন ধরনের নেটওয়ার্ক সেবা রয়েছে
  • কোন পোর্ট কোনো সার্ভিসের সঙ্গে সম্পর্কিত
  • সিস্টেমে কী ধরনের প্রযুক্তি ব্যবহৃত হতে পারে
  • নিরাপত্তা পরীক্ষার Scope কী

🔢 Port কী?

কম্পিউটার নেটওয়ার্কে Port হলো যোগাযোগের একটি logical endpoint। বিভিন্ন network service নির্দিষ্ট port-এর মাধ্যমে যোগাযোগ করতে পারে।

সহজ উদাহরণ

  • HTTP — সাধারণত Port 80
  • HTTPS — সাধারণত Port 443
  • SSH — সাধারণত Port 22

এগুলো সাধারণ উদাহরণ; বাস্তব সিস্টেমে configuration ভিন্ন হতে পারে।

🖥️ Service কী?

Service হলো কোনো সফটওয়্যার বা network application যা নির্দিষ্ট কাজের জন্য সিস্টেমে চলতে পারে।

উদাহরণ

  • Web Server
  • DNS Server
  • SSH Server
  • Database Service

📋 Enumeration কী?

Enumeration হলো অনুমোদিত পরিবেশে সংগৃহীত তথ্যকে আরও বিস্তারিতভাবে বোঝা ও সাজানো। এটি সাধারণত Scanning-এর পরবর্তী ধারণা হিসেবে শেখানো হয়।

উদ্দেশ্য

  • চলমান Service সম্পর্কে ধারণা তৈরি করা
  • প্রযুক্তি ও configuration সম্পর্কে তথ্য সাজানো
  • সম্ভাব্য নিরাপত্তা ঝুঁকি শনাক্ত করার প্রস্তুতি নেওয়া

🧪 নিরাপদ Practice Lab

Scanning শেখার জন্য নিজের কম্পিউটার, নিজের তৈরি Virtual Machine, অথবা অনুমোদিত Cyber Security Training Lab ব্যবহার করো।

আজকের অনুশীলন

  • Port কী তা নিজের ভাষায় লিখো।
  • Service কী তা বোঝার চেষ্টা করো।
  • HTTP এবং HTTPS-এর পার্থক্য পড়ো।
  • নিজের ল্যাবের Network Diagram তৈরি করো।

⚠️ গুরুত্বপূর্ণ নিরাপত্তা নিয়ম

কোনো বাস্তব ব্যক্তি, ওয়েবসাইট, সার্ভার বা নেটওয়ার্কে অনুমতি ছাড়া Port Scanning বা Enumeration করা যাবে না।

শুধুমাত্র নিজের সিস্টেম, অনুমোদিত ল্যাব অথবা বৈধ CTF পরিবেশে অনুশীলন করো।
