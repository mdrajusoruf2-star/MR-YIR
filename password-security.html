🔐 Password Security

শক্তিশালী পাসওয়ার্ড, নিরাপদ authentication এবং password protection সম্পর্কে প্রাথমিক ধারণা এই মডিউলে শেখা হবে।

📚 Password Security কী?

Password Security হলো ব্যবহারকারীর password এবং authentication তথ্যকে অননুমোদিত প্রবেশ থেকে সুরক্ষিত রাখার পদ্ধতি।

🎯 কেন গুরুত্বপূর্ণ?

  • ব্যক্তিগত অ্যাকাউন্ট সুরক্ষিত রাখতে
  • অননুমোদিত login প্রতিরোধ করতে
  • তথ্য চুরি ও account takeover-এর ঝুঁকি কমাতে
  • ব্যবহারকারীর privacy রক্ষা করতে

🔑 শক্তিশালী Password-এর বৈশিষ্ট্য

  • দীর্ঘ ও অনুমান করা কঠিন হওয়া
  • প্রতিটি গুরুত্বপূর্ণ অ্যাকাউন্টে আলাদা password ব্যবহার করা
  • ব্যক্তিগত তথ্য password-এ ব্যবহার না করা
  • Password manager ব্যবহার করার কথা বিবেচনা করা

🧠 Password Attack-এর ধারণা

নিরাপত্তা শিক্ষায় Password Attack বলতে দুর্বল authentication বা দুর্বল password শনাক্ত করার বিভিন্ন পদ্ধতির ধারণাকে বোঝানো হয়।

সাধারণ ধারণা

  • Brute Force — সম্ভাব্য password বারবার চেষ্টা করার ধারণা
  • Dictionary Attack — সাধারণ password-এর তালিকা ব্যবহার করার ধারণা
  • Password Reuse — একই password একাধিক সাইটে ব্যবহার করার ঝুঁকি
  • Credential Stuffing — অন্য উৎস থেকে ফাঁস হওয়া credentials পুনরায় ব্যবহারের ঝুঁকি

বাস্তব ব্যক্তি বা সিস্টেমের password পরীক্ষা করার পরিবর্তে এগুলো শুধুমাত্র নিজের অনুমোদিত lab-এ শেখা উচিত।

🧂 Password Hashing কী?

ভালোভাবে ডিজাইন করা সিস্টেমে password সরাসরি plain text হিসেবে সংরক্ষণ না করে নিরাপদ password hashing পদ্ধতি ব্যবহার করা হয়।

🔐 গুরুত্বপূর্ণ ধারণা

  • Password hashing একটি one-way cryptographic process
  • প্রতিটি password-এর জন্য নিরাপদ salt ব্যবহার করা উচিত
  • আধুনিক password hashing algorithm ব্যবহার করা গুরুত্বপূর্ণ
  • Plain-text password database-এ রাখা উচিত নয়

🛡️ Password নিরাপদ রাখার উপায়

  • দীর্ঘ ও unique password ব্যবহার করুন
  • Multi-Factor Authentication (MFA) চালু করুন
  • একই password বিভিন্ন সাইটে ব্যবহার করবেন না
  • অজানা login link বা phishing page এড়িয়ে চলুন
  • সন্দেহজনক login notification পেলে password পরিবর্তন করুন

🧪 নিরাপদ Practice Lab

নিজের তৈরি training application বা অনুমোদিত lab-এ password security পরীক্ষা করুন।

আজকের অনুশীলন

  • দুর্বল ও শক্তিশালী password-এর বৈশিষ্ট্য তুলনা করুন।
  • Password hashing কেন দরকার তা লিখুন।
  • MFA কীভাবে account security বাড়ায় তা পড়ুন।
  • নিজের জন্য একটি Password Security Checklist তৈরি করুন।

⚠️ গুরুত্বপূর্ণ নিয়ম

অনুমতি ছাড়া অন্য কারও account, password বা authentication system পরীক্ষা করা বেআইনি এবং ক্ষতিকর হতে পারে।

সব ধরনের security testing শুধুমাত্র নিজের account, নিজের lab অথবা স্পষ্টভাবে অনুমোদিত training environment-এ করুন।
