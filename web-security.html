🌐 Web Security

Web Application কীভাবে কাজ করে এবং সাধারণ নিরাপত্তা দুর্বলতাগুলো কীভাবে বোঝা ও প্রতিরোধ করা যায়—এই মডিউলে তার মৌলিক ধারণা শেখা হবে।

📚 Web Application Security কী?

Web Application Security হলো ওয়েবসাইট ও ওয়েব অ্যাপ্লিকেশনকে অননুমোদিত প্রবেশ, তথ্য ফাঁস এবং বিভিন্ন ধরনের নিরাপত্তা দুর্বলতা থেকে সুরক্ষিত রাখার প্রক্রিয়া।

🔐 নিরাপত্তার মূল লক্ষ্য

  • তথ্যের গোপনীয়তা রক্ষা করা
  • তথ্যের অখণ্ডতা বজায় রাখা
  • অনুমোদিত ব্যবহারকারীর জন্য সেবা সচল রাখা
  • ব্যবহারকারীর ইনপুট নিরাপদভাবে পরিচালনা করা

💉 SQL Injection কী?

SQL Injection হলো এমন একটি নিরাপত্তা দুর্বলতা যেখানে অনিরাপদভাবে পরিচালিত user input database query-এর অর্থ পরিবর্তন করতে পারে।

কেন ঝুঁকিপূর্ণ?

  • অননুমোদিত database তথ্য প্রকাশ হতে পারে
  • অ্যাপ্লিকেশনের data integrity ক্ষতিগ্রস্ত হতে পারে
  • অ্যাকাউন্ট authentication দুর্বল হতে পারে

🛡️ প্রতিরোধ

  • Parameterized Queries ব্যবহার করা
  • Prepared Statements ব্যবহার করা
  • Input validation করা
  • Database account-এ least privilege প্রয়োগ করা

📜 XSS কী?

Cross-Site Scripting বা XSS হলো এমন একটি দুর্বলতা যেখানে অনিরাপদ user input ওয়েব পেজে সঠিকভাবে নিরাপদ না করে প্রদর্শন করা হলে browser-এ অনাকাঙ্ক্ষিত script চালানোর সুযোগ তৈরি হতে পারে।

🛡️ প্রতিরোধ

  • Output encoding ব্যবহার করা
  • Input validation করা
  • Content Security Policy ব্যবহার করা
  • সঠিকভাবে HTML escaping করা

💻 Command Injection কী?

Command Injection হলো এমন একটি দুর্বলতা যেখানে অ্যাপ্লিকেশন user input-কে নিরাপদভাবে আলাদা না করে operating system command তৈরিতে ব্যবহার করলে অনাকাঙ্ক্ষিত command execution-এর ঝুঁকি তৈরি হতে পারে।

🛡️ প্রতিরোধ

  • সম্ভব হলে system command ব্যবহার এড়ানো
  • Allowlist ভিত্তিক input validation করা
  • নিরাপদ API ব্যবহার করা
  • অ্যাপ্লিকেশনকে কম privilege-এ চালানো
